# 亞洲事實査核實驗室內容備份

亞洲事實査核實驗室即將關閉，本專案為備份其中文與英文內容。

## 關於亞洲事實査核實驗室

[亞洲事實査核實驗室（Asia Fact Check Lab, AFCL）](https://www.rfa.org/mandarin/shishi-hecha/)是自由亞洲電台（Radio Free Asia, RFA）旗下的事實查核項目，專門針對亞洲地區的假訊息進行查證與分析。

## 關閉背景

2025年3月15日，美國總統川普簽署行政命令要求削減美國國際媒體署（U.S. Agency for Global Media）預算，導致自由亞洲電台失去聯邦政府資助。受此影響，RFA被迫大幅縮減營運規模，包括停止多個語言的短波廣播服務，並影響到旗下各項目的運作。

亞洲事實査核實驗室作為RFA的重要組成部分，也因此受到影響。該實驗室最後一次發布查核報告為2025年2月13日，之後因組織重整而停止運作。
